# TheRangerStar Homebrew Tap

CodeX视频壁纸的 Homebrew 安装源。

```sh
brew install therangerstar/tap/codex-wallpaper
codex-wallpaper
```

[项目介绍、演示和使用说明](https://github.com/TheRangerStar/codex-video-wallpaper)

升级：`brew update` 后运行 `brew upgrade codex-wallpaper`。

卸载前在工具菜单中关闭壁纸，再运行 `brew uninstall codex-wallpaper`。本地设置和原视频会保留。
